Qué sucede cuando llega un pedido

1
La web recibe el pedidoEl sistema obtiene cliente, productos y total.
2
La web llama a localhostEnvía JSON a http://127.0.0.1:8765/print con el token.
3
El agente transforma el ticketGenera comandos ESC/POS de 58 mm.
4
Windows imprime en ambasEl spooler recibe el trabajo RAW y no aparece el diálogo del navegador.
